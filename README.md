# 📚 Sistema de Alunos – Web + Mobile  
Aplicação completa com **React (Web)** e **Expo + React Native (Mobile)** consumindo a mesma **API REST de alunos**.

---

## 🚀 Tecnologias Utilizadas

### 🌐 Web
- React + Vite  
- Axios  
- React Router DOM  

### 📱 Mobile
- Expo  
- React Native  
- Expo Router  
- Axios  
- React Native Paper (opcional)

### 🌐 API
- Endpoint: `https://proweb.leoproti.com.br/alunos`
